# Agent Groups with Phased Static-to-Dynamic Membership

We evaluated decentralized peer-to-peer agent swarms versus centralized lead-orchestrated groups, as well as static group assignment versus dynamic recruitment. We decided that every Agent Group has a designated Lead Pill (admin) who controls orchestration and subtask delegation. In Phase 1, the user explicitly configures both the Lead Pill and static Member Pills upon group creation, with the Lead delegating work across those members. In Phase 2, we introduce dynamic recruitment, where the user selects the Lead Pill and grants it tool authority to dynamically recruit and add specialized Member Pills to the group based on task demands. This prevents uncoordinated peer loops while enabling future autonomous composition.
